# FontRelay · Web 字体发布验收台

品牌官网更换可变字体时，设计验收只能看到最终截图，复现不了慢网、缓存命中、文件失败时用户真正经历的过程。FontRelay 把 **真实文案从首屏到字体稳定后的每一帧** 拆开，逐字形给出匹配字体、换行、尺寸和布局偏移，并支持两个发布版本的逐帧对比。

React 18 + TypeScript + Vite 构建，仿真引擎为纯函数（无随机数、无真实时钟），相同输入永远得到相同时间线 —— 因此可以重复运行、留痕、导出验收记录。

## 启动

```bash
npm install
npm run dev        # 本地开发
npm test           # 运行全部测试（Vitest）
npm run build      # 类型检查 + 生产构建（dist/）
npm run preview    # 预览生产构建
```

## 能做什么

- **配置字体文件**：family、静态字重或可变 `wght` 区间（轴值钳制 + CSS Fonts 4 字重匹配：400 缺失先找 500、可变区间内请求视为精确命中）、字宽/行高系数、字符子集（ascii / latin1 / latinExt / vietnamese / cjk …）。
- **配置回退顺序**：可视化编辑 `font-family` 栈（增删、排序），系统族恒可用，web 回退字体也要加载、可失败。
- **选择场景**：中文 / Deutsch / Tiếng Việt / English 真实文案；容器宽度（360/280/768/1080 或自定义）、字号、行高。
- **加载故障**：正常网络、慢网 3G（耗时倍乘）、缓存命中（0ms 立即可用）、单文件失败、网络断开、`@font-face` 重复注入（检测并按 URL 去重）。
- **font-display 策略**：auto / block / swap / fallback / optional，block 与 swap 窗口时长可调；block 隐形期文字占位但不显示字形，optional/fallback 错过窗口永不替换。
- **逐步查看**：首屏 → block 结束 → 各字体落定 → 稳定，逐帧回放（单步 / 自动播放 / 拖动），舞台上每个字按命中字体着色，缺字显示 `.notdef` 豆腐块，隐形期文字虚位，元素尺寸/行数/偏移徽标实时标注。
- **度量**：每元素行数、宽高、缺字数、使用的字体族；逐字形明细表（码点、命中族、实际 wght、advance width）；帧间 CLS 增量与累计 CLS（新旧矩形并集 / 视口）。
- **定位第一次视觉变化**：自动标记与首屏签名不同的第一帧；事件流水（首屏、缓存、开始加载、到达、失败、block 结束、稳定、重复注入）随回放逐条点亮。
- **A/B 版本对比**：两版本配置并存，在共享时间轴上逐点对比，报告第一次版本差异时刻、最终逐元素的行数/高度/缺字/字体族差异。
- **验收**：CLS / 缺字 / 稳定时间门槛自动判定，保存验收记录，导出 JSON 或自包含离线 HTML 报告。
- **工程能力**：撤销/重做（Ctrl+Z / Ctrl+Shift+Z，上限 100 步）、localStorage 刷新恢复、重复运行 ×2 一致性校验（指纹比对）。

预置故事线：版本 A 是旧静态字体（Regular/Bold 两文件、仅 latin、字偏宽），版本 B 是新可变字体（单文件 100–900、含越南语子集、字略窄）。默认即可复现：**德语按钮换字体后突然换行**、**越南语带调字符落回系统字体**、首屏跳动。

## 代码结构

```
src/
  engine/
    types.ts        领域模型
    subsets.ts      字符子集 / unicode 覆盖
    languages.ts    四语言真实文案
    matching.ts     family+weight+style 匹配、可变轴、逐字形回退
    metrics.ts      确定性字宽、贪心换行（含 CJK 禁则）、元素矩形
    simulation.ts   加载时间线、font-display 窗口、帧签名、CLS、首变、版本 diff
    acceptance.ts   门槛判定与验收记录
    exportRecord.ts JSON / HTML 导出
    presets.ts      v1/v2 发布配置与故障预设
  state/            撤销重做历史、文档 store（localStorage）
  ui/               配置面板、舞台、回放器、事件流、度量、判定、对比、记录
  test/             44 个测试（匹配/回退/换行/CLS/重复运行/版本对比/UI 冒烟）
```

## 测试覆盖

- **字体匹配**：静态精确字重、400→500 规则、可变区间命中与钳制、越界回退静态。
- **回退**：首选未加载/不覆盖时的逐字形回退、全栈不覆盖的 `.notdef`、失败 source 剔除、web 回退字体未就绪跳过。
- **布局偏移**：字宽变化改变德语按钮行数、窄/宽容器换行差异、CLS 非负且增量可累加、block 隐形期占位。
- **加载故障**：慢网倍乘、缓存首屏即终态、文件失败、网络断开、optional/fallback 窗口、重复注入只发起一次请求、重复运行指纹一致。
- **版本对比**：共享时间轴首次差异定位、同配置无差异、越南语缺字差异捕获。
- **UI**：首屏渲染、单步回放、语言/版本切换、记录保存、撤销重做、A/B 双舞台。
